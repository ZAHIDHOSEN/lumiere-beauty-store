# LUMIÈRE — Cosmetics Storefront

A responsive cosmetics storefront homepage built with React, TypeScript, Tailwind CSS, Framer Motion, and React Router v7 using static product data.

## Features
- Responsive single-page storefront layout (`Navbar`, `Hero`, `ProductGrid`, `ProductCard`, `Philosophy`, `Footer`)
- Live search by product name or category
- Category filtering (`All`, `Skincare`, `Makeup`, `Fragrance`, `Haircare`)
- Subtle entrance and hover animations with Framer Motion
- Static showcase only (no backend, cart, or checkout)

## Tech Stack
- React + TypeScript + Vite
- React Router (`v7`)
- Tailwind CSS
- Framer Motion
- Lucide React
